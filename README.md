# Board Game Hub - Frontend Client

Фронтенд вебзастосунку реалізований через HTML5, CSS3 та ванільний JavaScript (`fetch API`) для взаємодії з REST API бекенду.

## Як запустити:

1. **Запустити бекенд:**
   Або переконатись, що бекенд вже працює на адресі `http://127.0.0.1:8000`.

2. **Запустіть фронтенд на іншому порті:**
   * **Варіант 1:** Якщо ви на VS Code, тоді запустіть **Live Server** (має запуститись на порті `http://127.0.0.1:5500`).
   * **Варіант 2:** через Python HTTP сервер. У терміналі всередині цієї папки виконайте:
     ```bash
     python -m http.server 5500
     ```
     і відкрийте в браузері `http://127.0.0.1:5500`.

3. **CORS:**
   Бекенд налаштовано на прийом запитів із порту `5500` та `63342`. Угорі сторінки зелений бейдж підтвердить успішне крос-доменне з'єднання.


## Поведінка

* Неавторизованого користувача, який відкриває сторінку для авторизованих, перенаправляє на сторінку логіну.
* Після логіну користувача повертає на сторінку, з якої його перенаправило на логін.
* Авторизований користувач не може відкрити сторінку логіну: його перенаправляє на сторінку з контентом.
* Неавторизований користувач бачить кнопку логіну і не бачить кнопки логауту.
* Авторизований користувач бачить кнопку логауту і своє ім'я (наприклад, поруч із нею) і не бачить кнопки логіну.
* Коли access токен закінчується, фронтенд оновлює його за допомогою refresh токена, не змушуючи користувача логінитися знову.
